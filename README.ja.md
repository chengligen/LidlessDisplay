# LidlessDisplay · 開いたまま外部ディスプレイだけを使う

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

MacBook の蓋を開いたまま内蔵ディスプレイをデスクトップから切り離し、外部ディスプレイだけを使うための小さな macOS メニューバーアプリです。録音や音声入力デバイスの変更は行いません。

Swift 製で、サードパーティーの依存ライブラリはありません。言語切り替えはドキュメントのみが対象です。アプリの画面表示は現在、簡体字中国語です。

## どんな問題を解決するのか

このプロジェクトは、MacBook に外部ディスプレイを 2 台接続し、その 2 台だけで作業しながら、通話や音声入力には内蔵マイクを使いたいという実際のニーズから生まれました。

蓋を閉じると外部ディスプレイだけのデスクトップになりますが、検証に使った MacBook では内蔵マイクも使えなくなりました。蓋を開けておけばマイクは使えるものの、不要な内蔵画面が残り、ポインタやウィンドウがその画面に移動してしまいます。明るさを最低にしても、画面はデスクトップの配置から消えません。

LidlessDisplay は、**蓋を開いたまま内蔵画面をデスクトップの配置から切り離し、外部ディスプレイだけに表示する**手動スイッチを提供します。画面を無効にするために蓋を閉じる必要がなく、内蔵マイクを使うための条件を維持できます。

外部ディスプレイを 1 台以上使い、内蔵マイクも引き続き使いたい方を想定しています。制御するのはディスプレイだけです。システムや通話アプリで内蔵マイクを選び、実際に音声が入力されることを確認してください。

## 機能

- 内蔵ディスプレイを手動で切断・復元。複数の外部ディスプレイに対応。
- 検証済みの P2710V プロファイルに対する、一時的な 144Hz EDID オーバーライドの適用・状態確認・解除。
- 切り替え後 20 秒以内に確定しなければ、内蔵ディスプレイの復元を試行。
- 外部ディスプレイがすべて切断された場合は復元を試行。通常終了時には、本アプリが無効にした内蔵ディスプレイを復元。
- アプリの起動だけでは内蔵画面を無効にせず、音声入力デバイスも変更しない。
- 内蔵画面のスイッチは現在のログインセッションの表示設定だけを変更。EDID オーバーライドは別の手動操作。

## P2710V のデュアルディスプレイ認識への対処

M4 Pro と P2710V 2 台の検証環境では、外部ディスプレイが 1 台しか認識されないことがありました。片方に上限 144Hz の一時的な EDID を適用すると、2 台とも動作するようになりました。根本原因は未確定で、オーバーライドが失われたこともあるため、手動で再適用できるようにしています。

メインメニューには内蔵画面のスイッチ、「144Hz オーバーライドを適用」（`应用 144Hz 覆盖…`）、終了を配置しています。スイッチは状態に応じて「外部ディスプレイのみ使用」（`仅用外接显示器`）または「内蔵画面を復元」（`恢复内屏`）と表示されます。状態確認（`检查覆盖状态…`）、工場出荷時の EDID に戻す操作（`取消覆盖，恢复原厂…`）、サウンド設定は「その他」（`更多`）にあります。**起動時に EDID の適用や内蔵画面の切断を自動実行しません。** 正常に動作しているデュアルディスプレイ接続を中断しないよう、終了時にも EDID のオーバーライドを解除しません。

適用・解除の手順：

1. MacBook の蓋を開け、内蔵画面を有効にします。本アプリで切断している場合は、先に「内蔵画面を復元」を選びます。
2. 以前に検証・バックアップした対象の P2710V だけを接続し、もう一方の外部ディスプレイの映像ケーブルを外します。
3. 操作を選び、読み戻しによる検証結果を待ちます。完了後に 2 台目を再接続します。

この機能は**特定の検証済み P2710V EDID 1 種類だけ**に対応しており、同じ型番のすべての個体に使えるわけではありません。2 ファイルの SHA-256、接続中の EDID との全バイト一致、対象が一意であることを確認し、不一致なら操作を拒否します。`IOAVServiceSetVirtualEDIDMode` による実行時のソフトウェア上の置き換えであり、モニターのファームウェアは書き換えません。検証に失敗すると操作前の状態への復元を試み、その復元を確認できたか報告します。

公開リポジトリには個別のモニターの EDID データを含めていません。この機能を使う場合は、プロジェクト直下に Git の追跡対象外となる `EDID/` を作り、次の**以前に検証済みのファイル**を配置して再ビルドしてください。

- `P2710V_EDID_original.bin`、SHA-256：`be791d6ffbe772e6464bc5346e7f0f93e2e794dff72c6f7ced148278bd892b03`
- `P2710V_EDID_max144.bin`、SHA-256：`39bc876b9062f9951ca373ba76ca6163097a7f9fc85b7c08e1f9a2d566376e56`

ローカルビルドではこの 2 ファイルがアプリに組み込まれるため、そのアプリや ZIP の配布には EDID データも含まれます。ファイルがなくても内蔵画面スイッチはビルド・使用でき、EDID 操作時には設定不足のメッセージが出ます。別のモニターのファイルをリネームして流用しないでください。

## 使い方

1. `build/LidlessDisplay.app` を開き、メニューバーのノートパソコンと矢印のアイコンを探します。
2. 蓋を開いたまま、外部ディスプレイを接続します。
3. 「外部ディスプレイのみ使用」（`仅用外接显示器`）を選びます。一瞬画面がちらつく場合があります。
4. 20 秒以内にメニューを開き直し、「設定を維持」（`保留设置`）を選びます。確定しなければ内蔵画面の復元を試みます。
5. 必要に応じて「内蔵画面を復元」（`恢复内屏`）を選べます。アプリの実行中に外部画面がすべて切断されると復元を試み、通常終了時も本アプリが無効にした内蔵画面を復元します。

システム設定 → サウンド → 入力で「MacBook Pro のマイク」を選択してください。蓋を開けておくことで、合蓋によるマイクのハードウェア切断を避けます。アプリはマイクの権限を要求しません。実際の音声入力は通話・録音アプリで確認してください。

## ビルドと確認

Apple Silicon 搭載 Mac、macOS 26 以降、Swift を含む Xcode Command Line Tools が必要です。他の機種・OS バージョンでの互換性は未検証です。

```sh
git clone https://github.com/chengligen/LidlessDisplay.git
cd LidlessDisplay
zsh build.sh
open build/LidlessDisplay.app
```

`build/LidlessDisplay.app` と `build/LidlessDisplay.zip` が生成されます。アプリはローカルのアドホック署名を使用しており、Apple の公証は受けていません。

コマンドラインでの確認・復元：

```sh
build/LidlessDisplay.app/Contents/MacOS/LidlessDisplay --status
build/LidlessDisplay.app/Contents/MacOS/LidlessDisplay --restore
```

`--test` は、蓋を開けて内蔵画面を有効にした状態から内蔵画面を切断し、3 秒待って音声デバイスを列挙した後、画面を復元して状態を確認します。テスト中は画面配置が変わります。

2026-09-08 に M4 Pro / macOS 26.6.2 と外部ディスプレイ 2 台で実測しました。内蔵画面は active=1 から 0 へ変わり、外部画面 2 台は active=1 を維持し、復元後に内蔵画面は active=1 に戻りました。切断中も「MacBook Pro のマイク」は列挙されました。これはデバイスが認識されることだけの確認です。実際の録音、20 秒後の復元、ケーブル切断時の復元、スリープ復帰の完全なテストは未実施です。

## ログイン時の起動

アプリ自身はログイン項目への登録を行いません。必要なら macOS のログイン項目に追加できます。起動時はメニューバーに表示されるだけで、外部ディスプレイのみの使用には手動操作が必要です。登録後はアプリの保存場所を変えないでください。

## 制限と復元

- 非公開の SkyLight / IOKit API を使うため、macOS の更新後に動作しなくなる可能性があります。内蔵画面スイッチはセッションの設定を変更し、手動 EDID オーバーライドはハードウェアに書き込まず、システムに通知する表示モードを変更します。
- スリープや再接続で内蔵画面が復元される場合があります。必要に応じて再度手動で切り替えてください。
- 自動復元にはアプリの継続動作が必要です。強制終了やクラッシュ時の復元は保証できません。アプリを開き直して「内蔵画面を復元」を選ぶか、`--restore` を実行してください。外部画面の切断と蓋の開閉によりシステムの再検出を促すこともできます。
- 切り替え時には一時的な黒画面、ウィンドウの再配置、メインディスプレイの変更が起こる場合があります。

表示 API の参考資料：[ScreenTune](https://github.com/antonorlov/screen_tune)、[displaytoggle](https://github.com/calvincchan/displaytoggle)。

EDID API の参考資料：[mac-edid-override](https://github.com/kdotc2/mac-edid-override)。バージョン 1.1 ではビルド、署名、現在のオーバーライドの読み戻し、破損・不一致ファイルや外部画面 2 台接続時の操作拒否を確認しています。新版での適用・解除・異常時ロールバックの一連の実機テストは、対象外部画面 1 台の構成で引き続き必要です。以前の単独ツールでの適用は成功しています。
