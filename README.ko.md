# LidlessDisplay · 덮개를 열고 외부 모니터만 사용하기

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

MacBook 덮개를 열어 둔 채 내장 디스플레이를 데스크톱에서 분리하여 외부 모니터만 사용할 수 있게 해 주는 작은 macOS 메뉴 막대 앱입니다. 녹음하거나 오디오 입력 장치를 변경하지 않습니다.

Swift로 작성되었으며 외부 라이브러리에 의존하지 않습니다. 언어 선택은 문서에만 적용됩니다. 앱 화면은 현재 중국어 간체로 표시됩니다.

## 어떤 문제를 해결하나요?

이 프로젝트는 MacBook에 외부 모니터 두 대를 연결한 작업 환경에서 시작되었습니다. 두 모니터만 사용하면서 통화나 음성 입력에는 노트북의 내장 마이크를 계속 쓰고 싶었습니다.

덮개를 닫으면 외부 모니터만 남지만, 테스트에 사용한 MacBook에서는 내장 마이크도 사용할 수 없게 되었습니다. 덮개를 열어 두면 마이크는 사용할 수 있지만, 필요 없는 내장 화면에 창이나 포인터가 들어갈 수 있습니다. 밝기를 최저로 낮추는 것만으로는 내장 화면이 데스크톱 배치에서 제거되지 않습니다.

LidlessDisplay는 **덮개를 열어 둔 채 내장 화면을 데스크톱 배치에서 분리하고 외부 모니터에만 화면을 표시하는** 수동 스위치를 제공합니다. 화면을 끄려고 덮개를 닫을 필요가 없어 내장 마이크를 사용할 수 있는 조건을 유지합니다.

외부 모니터를 한 대 이상 사용하면서 내장 마이크도 계속 쓰려는 사용자를 위한 도구입니다. 앱은 디스플레이만 제어합니다. 시스템이나 통화 앱에서 내장 마이크를 선택하고 실제로 소리가 입력되는지 확인하세요.

## 기능

- 내장 디스플레이를 수동으로 분리하거나 복원하며 여러 외부 모니터를 지원합니다.
- 검증된 P2710V 프로필에 임시 144Hz EDID 오버라이드를 적용하고, 상태를 확인하거나 해제합니다.
- 화면 전환 후 20초 안에 확정하지 않으면 내장 화면 복원을 시도합니다.
- 모든 외부 모니터가 분리되면 내장 화면 복원을 시도하며, 정상 종료 시에는 앱이 비활성화한 내장 화면을 복원합니다.
- 앱을 실행해도 내장 화면을 자동으로 끄거나 오디오 입력 장치를 변경하지 않습니다.
- 내장 화면 스위치는 현재 로그인 세션의 디스플레이 설정만 변경합니다. 144Hz EDID 오버라이드는 자동 복원을 지원합니다.

## P2710V 듀얼 모니터 인식 문제 대응

M4 Pro와 P2710V 두 대로 구성된 테스트 환경에서 외부 모니터가 한 대만 인식되는 문제가 있었습니다. 한 대에 최대 144Hz로 제한한 임시 EDID를 적용하자 두 모니터가 모두 작동했습니다. 근본 원인은 아직 확인되지 않았으며 오버라이드가 사라진 사례도 있어 수동 재적용 기능을 제공합니다.

기본 메뉴에는 내장 화면 스위치, 144Hz 오버라이드 적용(`应用 144Hz 覆盖…`), 종료가 있습니다. 스위치는 상태에 따라 외부 모니터만 사용(`仅用外接显示器`) 또는 내장 화면 복원(`恢复内屏`)으로 표시됩니다. 오버라이드 상태 확인(`检查覆盖状态…`), 해제 및 공장 EDID 복원(`取消覆盖，恢复原厂…`), 사운드 설정은 더 보기(`更多`)에 있습니다. **앱 시작 시 내장 화면을 자동으로 끄지 않습니다.** 더 보기 → 144Hz 자동 복원(`更多 → 自动恢复 144Hz`)은 기본으로 켜져 있습니다. 앱 시작이나 화면 깨우기 약 3초 후부터 15초마다 확인합니다. 이미 적용된 경우 다시 쓰지 않고, 사라진 경우에만 전체 EDID가 일치하는 유일한 대상에 재적용합니다. 외부 모니터 두 대가 연결되고 내장 화면이 꺼져 있어도 가능합니다. 잠자기 중에는 확인하지 않으며, 쓰기나 검증 실패 시 다음 깨우기 또는 수동 재활성화까지 재시도를 중단합니다. 대상이 없거나 하나로 특정되지 않으면 건너뛰고 나중에 다시 확인하며 대화상자는 띄우지 않습니다. 오버라이드 해제 시 자동 복원도 꺼지고, 수동 적용에 성공하면 다시 켜집니다. 정상 작동 중인 듀얼 모니터 연결을 방해하지 않도록 앱을 종료해도 EDID 오버라이드는 해제하지 않습니다.

오버라이드를 수동으로 적용하거나 해제하려면(자동 복원에는 이 단일 모니터 준비가 필요하지 않습니다):

1. MacBook 덮개를 열고 내장 화면을 켜 둡니다. 앱으로 내장 화면을 분리했다면 먼저 내장 화면 복원을 선택하세요.
2. 이전에 검증하고 EDID를 백업한 대상 P2710V만 연결하고, 다른 외부 모니터의 영상 케이블은 분리합니다.
3. 작업을 선택하고 데이터를 다시 읽어 검증한 결과를 기다립니다. 완료 후 두 번째 모니터를 다시 연결합니다.

현재 기능은 **검증된 특정 P2710V EDID 한 가지에만** 대응하며 같은 모델의 모든 모니터에 사용할 수 있는 것은 아닙니다. 도구는 두 파일의 SHA-256, 연결된 모니터 EDID와의 전체 바이트 일치 여부, 대상이 하나뿐인지 확인하고 불일치하면 작업을 거부합니다. `IOAVServiceSetVirtualEDIDMode`를 통한 실행 중 소프트웨어 오버라이드이며 모니터 펌웨어를 쓰지 않습니다. 검증에 실패하면 작업 전 상태로 복원을 시도하고 복원 검증 결과를 알립니다.

공개 저장소에는 개별 모니터의 EDID 데이터가 포함되지 않습니다. 이 기능을 사용하려면 프로젝트 루트에 Git 추적에서 제외되는 `EDID/` 폴더를 만들고 다음 **이전에 검증한 파일 두 개**를 넣은 뒤 다시 빌드하세요.

- `P2710V_EDID_original.bin`, SHA-256: `be791d6ffbe772e6464bc5346e7f0f93e2e794dff72c6f7ced148278bd892b03`
- `P2710V_EDID_max144.bin`, SHA-256: `39bc876b9062f9951ca373ba76ca6163097a7f9fc85b7c08e1f9a2d566376e56`

로컬 빌드에는 두 파일이 앱에 포함되므로 해당 앱이나 ZIP을 배포하면 EDID 데이터도 함께 전달됩니다. 파일이 없어도 내장 화면 스위치는 빌드하고 사용할 수 있으며, EDID 작업 시에는 설정이 없다는 안내가 표시됩니다. 다른 모니터의 파일 이름을 바꿔서 사용하지 마세요.

## 사용 방법

1. `build/LidlessDisplay.app`을 열고 메뉴 막대에서 노트북과 화살표 모양 아이콘을 찾습니다.
2. 덮개를 열어 둔 채 외부 모니터를 연결합니다.
3. 외부 모니터만 사용(`仅用外接显示器`)을 선택합니다. 화면이 잠깐 깜박일 수 있습니다.
4. 20초 안에 메뉴를 다시 열고 설정 유지(`保留设置`)를 선택합니다. 확정하지 않으면 내장 화면 복원을 시도합니다.
5. 필요할 때 내장 화면 복원(`恢复内屏`)을 선택할 수 있습니다. 앱 실행 중 외부 모니터가 모두 분리되면 복원을 시도하고, 정상 종료 시에도 앱이 비활성화한 내장 화면을 복원합니다.

시스템 설정 → 사운드 → 입력에서 MacBook Pro 마이크를 선택하세요. 덮개를 열어 두면 덮개를 닫을 때 발생하는 마이크의 하드웨어 연결 해제를 피할 수 있습니다. 앱은 마이크 권한을 요청하지 않습니다. 실제 음성 입력은 통화 또는 녹음 앱에서 확인해야 합니다.

## 빌드 및 확인

Apple Silicon Mac, macOS 26 이상, Swift가 포함된 Xcode Command Line Tools가 필요합니다. 다른 기기나 OS 버전과의 호환성은 검증하지 않았습니다.

```sh
git clone https://github.com/chengligen/LidlessDisplay.git
cd LidlessDisplay
zsh build.sh
open build/LidlessDisplay.app
```

빌드하면 `build/LidlessDisplay.app`과 `build/LidlessDisplay.zip`이 생성됩니다. 앱은 로컬 임시 서명을 사용하며 Apple 공증을 받지 않았습니다.

명령줄 상태 확인 및 복원:

```sh
build/LidlessDisplay.app/Contents/MacOS/LidlessDisplay --status
build/LidlessDisplay.app/Contents/MacOS/LidlessDisplay --restore
```

`--test`는 덮개가 열리고 내장 화면이 켜진 상태에서 내장 화면을 분리한 뒤, 3초를 기다리고 오디오 장치 목록을 읽습니다. 이후 화면을 복원하고 상태를 확인합니다. 테스트 중 디스플레이 배치가 변경됩니다.

2026-09-08에 M4 Pro / macOS 26.6.2와 외부 모니터 두 대로 확인했습니다. 내장 화면은 active=1에서 0으로 바뀌고, 외부 화면 두 대는 active=1을 유지했으며, 복원 후 내장 화면은 active=1로 돌아왔습니다. 내장 화면이 분리된 동안에도 MacBook Pro 마이크가 목록에 표시되었습니다. 이는 장치가 인식된다는 것만 확인한 결과입니다. 실제 녹음, 20초 후 복원, 케이블 분리 시 복원, 잠자기 및 깨우기는 완전히 테스트하지 않았습니다.

## 로그인 시 실행

앱은 스스로 로그인 항목에 등록하지 않습니다. 필요하면 macOS 로그인 항목에 추가할 수 있습니다. 실행 시 메뉴 막대에 도구만 표시되며 외부 모니터만 사용하려면 직접 선택해야 합니다. 설정 후에는 앱의 위치를 변경하지 마세요.

## 제한 사항과 복원

- 비공개 SkyLight / IOKit API를 사용하므로 macOS 업데이트 후 작동하지 않을 수 있습니다. 내장 화면 스위치는 세션 설정을 변경하고, EDID 오버라이드는 하드웨어에 기록하지 않고 시스템에 알리는 표시 모드를 변경합니다.
- 잠자기나 재연결 후 내장 화면이 복원될 수 있습니다. 필요하면 다시 수동으로 전환하세요.
- 자동 복원은 앱이 계속 실행 중이어야 가능합니다. 강제 종료나 충돌 시 복원을 보장할 수 없습니다. 앱을 다시 열어 내장 화면 복원을 선택하거나 `--restore`를 실행하세요. 외부 모니터를 분리하고 덮개를 닫았다 열어 시스템의 재인식을 유도할 수도 있습니다.
- 화면 전환 시 잠깐 검은 화면이 나타나거나 창 배치 또는 주 디스플레이가 바뀔 수 있습니다.

디스플레이 API 참고: [ScreenTune](https://github.com/antonorlov/screen_tune), [displaytoggle](https://github.com/calvincchan/displaytoggle).

EDID API 참고: [mac-edid-override](https://github.com/kdotc2/mac-edid-override). 버전 1.1은 빌드, 서명 검증, 현재 오버라이드 읽기, 손상되거나 불일치하는 파일과 외부 모니터 두 대 연결 상태에서의 작업 거부를 확인했습니다. 새 앱의 적용/해제 및 실패 시 롤백 전체 과정은 대상 외부 모니터 한 대를 연결한 상태에서 추가 실기 테스트가 필요합니다. 이전 독립 도구에서는 일회성 적용에 성공했습니다.

2026-10-19에 M4 Pro / macOS 27.0.1에서 1.2 자동 복원을 확인했습니다. 대상 오버라이드를 임시로 해제하자 실행 중인 앱이 약 2초 안에 재적용했고, 다시 읽은 데이터가 일치했습니다. 외부 모니터 두 대는 온라인을 유지했으며 테스트 후 원래의 내장 화면 꺼짐 상태로 복원했습니다. 시작, 잠자기/깨우기 지연, 동시 실행 방지, 확인 간격, 실패 시 중단, 스위치는 가짜 도우미로 테스트했습니다(`python3 tests/test_automatic_edid.py`, macOS GUI 세션 필요). 실제 화면 전원 끄기, 잠자기, 케이블 재연결 후의 장기 안정성은 일상 사용 중 추가 확인이 필요합니다.
